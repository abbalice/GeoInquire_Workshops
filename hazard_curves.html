Hazard curves¶

Express the probability of exceeding some intensity levels at a target site, over a specific time window.

Input data

  1. An ensemble $\{s\}$ of scenarios $s$
  2. Annual occurrence rates $\{r_i(s)\}$ of each scenario, depending on the model $i$
  3. Tsunami intensity $\{I(s)\}$ for each scenario
  4. Intensity threshold $I_t$ to be exceeded.

The annual exceedance-rate according to the i-th rate model $r_i$ is computed as:

$\lambda_i(I > I_t) = \sum_s P(I(s) > I_t | s) r_i(s)$

where

$ P(I(s) > I_t | s) = \begin{cases} 1 \quad \textit{if} \quad I(s) > I_t \\ 0 \quad \textit{otherwise} \end{cases} $

def exceedance_curve(thresholds, intensity, rates):
    nEnsemble = rates.shape[1]
    # Annual Mean Rate of threshold exceedance
    lambda_exc = np.empty([len(thresholds), nEnsemble])
    for ith, threshold in enumerate(thresholds):
        ix_sel = intensity > threshold
        for j in range(nEnsemble):
            lambda_exc[ith, j] = rates[ix_sel,j].sum(axis=0)
    return lambda_exc

def extract_flowdepth_point(simuldir, scenario_ids, ncfile, lats, lons):
    nscen   = len(scenario_ids) 
    npoints = len(lats) 
    flowdepth_pois = np.empty([nscen, npoints])
    for poi in range(npoints): 
        for iscen, idscen in enumerate(scenario_ids): 
            if os.path.exists(os.path.join(simuldir, 'BS', idscen)): 
                tmp_flowdepth = os.path.join(simuldir, 'BS', idscen, ncfile) 
            else: 
                tmp_flowdepth = os.path.join(simuldir, 'PS', idscen, ncfile)
            open_file = xr.open_dataset(tmp_flowdepth, engine='netcdf4') 
            flowdepth_pois[iscen, :] = open_file['z'].values[lats, lons] 
    return flowdepth_pois

def computeHC(simuldir, scenario_ids, rates, ncfile, lats, lons, thresholds):
    nEnsemble     = rates.shape[1] 
    npoints       = len(lats)
    lambda_total  = np.zeros((npoints, len(thresholds), nEnsemble)) 
    tmp_flowdepth = extract_flowdepth_point(simuldir, scenario_ids, ncfile, lats, lons) 
    for poi in range(npoints): 
        fdTmp = tmp_flowdepth[:, poi] 
        lambdaCumTmp = exceedance_curve(thresholds, fdTmp, rates) 
        lambda_total[poi, :, :] = lambdaCumTmp 
    return lambda_total

From annual exceedance rate to probability¶

The probability of exceeding an intensity threshold $I_t$ over a time window dt is given by

$P(I > I_t) = 1 - e^{-\lambda(I > I_t) dt}$

where $\lambda(I > I_t)$ is the annual exceedance-rate, and $dt$ is the duration of the time-window.

Example For $dt = 50$ years, $P = 0.1$ is the 10% probability of exceeding $I_t$ in 50 years.

The Average Return Period (ARP) is defined as:

$T = -\frac{dt}{\ln{(1-P)}}$

In [21]:
def poisson_dist(lambda_exc, dt):
    p = 1 - np.exp(-lambda_exc*dt)
    return p

def arp(prob_exceedance, exposure_time):
    t = -np.log(1-prob_exceedance) / exposure_time
    T =  np.round(1/t)    
    return T

def get_intensity(hc, mih, p_th):
    n_mih = np.shape(hc)
    curve = hc
    if (p_th < curve[0] and p_th > curve[-1] ):
        for j in range(len(curve)):
            if (curve[j] < p_th):
                interp = (mih[j]-mih[j-1]) * (p_th-curve[j-1]) / (curve[j]-curve[j-1])
                z = mih[j-1]+interp
                break
    elif (p_th >= curve[0]):
           z = 0
    elif (p_th <= curve[-1]):
           z = 0
    else:
          pass

    return z
